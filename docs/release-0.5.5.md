## Mono and stereo

- The button next to Output Gain shows a single ring in mono and two overlapping rings in stereo.
- Stereo processes the left and right inputs independently through the same selected NAM or PNAM model and IR. Parametric controls, model size, gain, and IR bypass remain shared.
- Mono uses the left input and sends the same processed signal to both outputs. Existing sessions default to mono. Stereo requires a host layout with two input channels.
